# 🎮 Hangman Game (Python)

A simple and fun **Hangman game written in Python**, featuring:

* 🖼 **ASCII Hangman drawings**
* 📚 **Multiple word categories**
* 🎯 Clean and beginner-friendly code
* 📝 Fully playable in the terminal

---

## 🚀 Features

✔ ASCII hangman drawings (7 stages)
✔ Multiple categories (Animals, Fruits, Tech, Countries, School)
✔ Tracks used letters
✔ Prevents duplicate guesses
✔ Random word selection
✔ Beginner-friendly and fully offline

---

hangman.py
README.md

## ▶️ How to Run the Game

1. Make sure Python is installed
2. Download or clone this repository
3. Open terminal inside the project folder
4. Run:

```bash
python hangman.py
```
